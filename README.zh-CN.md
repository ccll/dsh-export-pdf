# dsh-export-pdf

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

[English](README.md) | 简体中文

DeepSeek Harness（DSH）Web 插件：在会话视图区增加一个 **PDF 页**。打开该页即可看到当前会话转录生成的 PDF 预览，点一下即可下载同一份文件；不选格式、不填参数、不跳转到外部转换工具。

> **状态：设计阶段。** 仓库目前承载项目的需求、方案与决策文档，尚无可用实现，首个实现任务也尚未立项。安装方式将随首个版本一起发布。

## 计划行为

- **PDF 页**：会话视图区内的一个视图页，同时提供预览与下载。
- **页内预览**：生成的 PDF 就地呈现，可浏览全部页面。
- **下载**：交付同一份字节，文件名为 `dsh-session-<会话标识前 8 位>.pdf`。
- **转录可信**：用户消息与助手回复按日志顺序呈现，工具调用各以单行摘要呈现，思考块不呈现正文。
- **中文可读**：嵌入中文字形，按 A4 分页，内容不越出页面边界。
- **失败可见**：会话不存在、日志读取失败、渲染失败、缺少浏览器或缺少中文字体，都会在页内给出明确提示，且不留下半份文件。
- **仅限已认证的同源请求**：预览与下载请求缺少有效凭据或来自异源时一律拒绝。

## 开发

当前唯一可执行的检查是 AgentMap 文档 lint：

```sh
python3 tools/agentmap_lint.py --report
```

Git 钩子位于 `.githooks/`，需要在每个克隆中单独启用：

```sh
git config core.hooksPath .githooks
```
