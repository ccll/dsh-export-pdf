# C-004 会话归属校验交由宿主鉴权边界

日期: 2026-11-16

#### 上下文

SOLUTION 的安全边界原写“插件校验 `sessionId` 属于当前可见会话”。导出路由是宿主 `/api` 通道上的同源、无状态请求：经浏览器会话鉴权后，服务端拿不到“页面当前可见哪个会话”。若由客户端附带会话令牌或当前会话头，同源脚本同样可以伪造，只会增加表面检查而不形成安全边界。

#### 决策

插件只校验 `sessionId` 的格式、非空与长度；会话归属与访问控制由宿主的浏览器会话鉴权与 Host/Origin 栅栏承担。路由不判断页面当前可见会话，也不接受客户端自证。

#### 被否方案及原因

- 客户端附带请求令牌/当前会话头：同源脚本可伪造，安全检查不可信，还要新增契约。
- 服务端列出全部会话并比对：只能证明会话可读，无法表达“当前可见”，且为一次导出引入 O(n) 列表成本。
- 保留原承诺并记为差距：实现无法兑现，任务不能按黄金标准关闭。

#### 影响面

R-01-008 · 会话导出（T-001）
