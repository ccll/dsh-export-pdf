# C-003 空白会话的空态验收改为宿主渲染该页时成立

日期: 2026-11-16

#### 上下文

R-01-001/AC-03 要求“会话尚未产生任何消息时，在该页显示空态说明，且不发起 PDF 生成”。DSH 的会话页在 `session.blank` 且 `conversationPhase` 为 `blank` 时直接不渲染视图区（`DefaultConversationViews` 返回 `null`），因此任何 `conversation.view` 条目——包括 PDF 页——都无法出现在页面上。插件无法在不改宿主的前提下让该页在真正空白的会话里可见。

#### 决策

把 AC-03 的可见性条件改为“当宿主渲染该页且会话尚未产生任何消息时”：插件保证此时显示空态说明且不发起生成；宿主在 blank 阶段隐藏视图区时不渲染该页，也不产生请求。不修改宿主，不新增其它入口。

#### 被否方案及原因

- 修改宿主视图区，让 blank 阶段也渲染视图区：违反本 task 的非目标，且会改变所有视图页的呈现。
- 在 hero 或侧栏另加 PDF 入口：改变已确认的 PDF 视图页交互，超出当前设计。
- 保持 AC 原文并把任务标为阻塞：AC 在现有宿主上不可判定，任务无法收口，且问题不在插件实现。

#### 影响面

R-01-001 · 会话导出（T-001）
