# C-001 用本机 Chromium 打印 HTML 生成 PDF

日期: 2026-11-16

#### 上下文

导出必须中文正确、按 A4 分页。插件要轻量：不引入常驻依赖，也不让安装体积膨胀。宿主机器已经装了 Chromium 系浏览器，可用作渲染器。

#### 决策

把会话折叠成 HTML，再调用本机 Chromium 系浏览器的无头模式打印成 PDF。

#### 被否方案及原因

- 纯 JS 直接写 PDF：需要内嵌中文字体子集，还要自研断行与分页，代码量与安装体积都是三条路里最大的。
- 浏览器打印对话框：不产生 PDF 字节，无法在 PDF 视图页内预览，与 R-01-002 直接冲突。
