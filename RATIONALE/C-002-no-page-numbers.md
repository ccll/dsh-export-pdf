# C-002 首个版本不提供页码

日期: 2026-11-16

#### 上下文

多页 PDF 通常需要页码。实测 Chrome 156 的打印路径后，三条可行做法各有代价：默认页眉页脚、CSS 页码计数器、生成后盖章。

#### 决策

首个版本不打印页眉页脚与页码，页面内容只来自转录。

#### 被否方案及原因

- Chrome 默认页眉页脚：确实印出页码，但同时印出日期、标题与 `file://` 临时文件路径，把宿主磁盘路径泄漏进用户文件。
- CSS 页码计数器：打印路径下不生效，固定定位元素在 3 页样本里只重复了 2 次，不可依赖。
- CDP 自定义页脚模板：能只印页码，但需要在宿主实现 DevTools 协议客户端，超出一个轻量插件的必要复杂度。
- 生成后用 pdf-lib 盖章：可行且页码只需拉丁数字，但为此引入运行时依赖，与本项目零依赖约束冲突。
